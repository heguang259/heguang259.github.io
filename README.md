**动手之前，请务必先完整读一遍 [`MAINTENANCE.md`](MAINTENANCE.md)（中文：核心维护手册）。**

## 这个仓库是什么

| 项目 | 说明 |
|---|---|
| 站点名 | 心照笔记 |
| 生成工具 | Hugo（中文：静态网站生成器，把 Markdown 文章变成网页） |
| 页面主题 | PaperMod（一套现成的网页外观模板） |

> `main` 分支（中文：主分支，仓库的正式版本线）

## 常用文件在哪

| 想改什么 | 去哪个位置 |
|---|---|
| 文章正文 | `content/posts/` 目录下的 `.md` 文件 |
| 图片 | `assets/images/` 目录 |
| 网站整体设置（站名、菜单等） | `hugo.toml` |
| 自定义样式 | `assets/css/extended/custom.css` |
| **维护手册（先读这个）** | `MAINTENANCE.md` |

---

## 写文章的最简流程

1. 在 `content/posts/` 新建一个 `.md` 文件
2. 文件开头按固定格式写标题、日期等信息（详见手册第四节）
3. 正文开头段落之后，单独一行加上 `<!--more-->`（这是"摘要分割线"）
4. 本地预览确认效果 → 提交 → 推送
